# 界面设计文档 (UI Design Specification)

## 文档说明

本文档定义 MarketMind AI 前端所有页面的界面设计规范，包括布局结构、组件规范、交互细节和数据展示。

---

## 1. 全局布局

### 1.1 整体结构

```
┌──────────────────────────────────────────────┐
│ 左侧边栏(280px) │         主工作区           │
│                  │ ┌──────────────────────┐   │
│  ┌──────────┐    │ │      顶栏            │   │
│  │ 品牌区    │    │ ├──────────────────────┤   │
│  ├──────────┤    │ │                      │   │
│  │ 导航菜单  │    │ │    页面内容区         │   │
│  │          │    │ │                      │   │
│  │          │    │ │                      │   │
│  ├──────────┤    │ │                      │   │
│  │ 版本信息  │    │ └──────────────────────┘   │
│  └──────────┘    │              💬 AI助手FAB   │
└──────────────────────────────────────────────┘
```

### 1.2 侧边栏 (Sidebar)

**位置**: 左侧固定，宽280px，深色背景(#101820)
**结构**:

| 区域 | 内容 | 样式 |
|------|------|------|
| 品牌区 | 白色方块"AI" + "MarketMind AI" + "智能铺货·深度分析" | padding 22px 20px, 底部分割线 |
| 导航菜单(Nova模式) | 仪表板📊 / 一键选品🎯 / 一键货源📦 / 一键优化✨ / 一键维护🔄 | 每项高42px, 圆角8px, hover白色10%透明背景 |
| 导航菜单(Horizon模式) | 仪表板📊 / 爆品追踪🔥 / 竞品分析🕵️ / 六维诊断📊 | 同上 |
| 底部 | 版本号 | 居中, 12px, 白色30%透明 |

**导航高亮**: 当前路由匹配的项背景 rgba(255,255,255,0.1)，文字白色

### 1.3 顶栏 (TopBar)

**位置**: 主工作区顶部，高约60px
**结构**: 

| 位置 | 内容 | 说明 |
|------|------|------|
| 左 | 面包屑 "MarketMind AI / 页面名" | 13px 灰色文字 |
| 右 | 模式切换 + 用户头像 | Nova/Horizon 切换按钮组 + 头像+名字 |

**模式切换**: 灰色背景圆角组，激活项蓝色背景白色文字
**用户区**: 圆形头像(首字) + 用户名，hover灰色背景

### 1.4 AI助手

**位置**: 右下角固定浮动
**触发**: 圆形蓝色按钮(56px)，内含💬图标
**展开**: 380×520px面板

| 区域 | 设计 |
|------|------|
| 头部 | 深色背景(#101820)，AI图标+标题+在线状态+关闭按钮 |
| 消息区 | AI消息灰色背景靠左，用户消息蓝色背景靠右 |
| 快捷问题 | 圆角标签按钮，首次打开显示4个预设问题 |
| 输入区 | 文本输入框 + 发送按钮 |

### 5.2 卡片

```css
标准卡片:
  background: var(--surface)
  border: 1px solid var(--line)
  border-radius: 12px
  padding: 20px

hover效果:
  transform: translateY(-4px)
  box-shadow: var(--shadow)
```

### 5.3 按钮

- 主要操作: El-Button type="primary" (蓝色)
- 次要操作: El-Button default
- 禁用操作: El-Button disabled (灰色)
- 危险操作: El-Button type="danger" (红色)

### 5.4 进度反馈

- 上架/下单/优化/维护: El-Dialog + El-Progress
- 完成后: El-Notification type="success"

### 5.5 表格

- 使用 El-Table + stripe
- 列: 选择框 / 优先级Tag / 文字 / 金额(绿色) / 操作
