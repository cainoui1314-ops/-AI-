# 交互流程设计

## 模式A交互流程（一键操作）

### 1. 商家类型选择 → 模式A

#### 用户操作
- 点击"铺货型商家"选择按钮

#### 系统响应
- 页面跳转到 mode-a.html
- 自动标记模式A为当前模式

#### 交互逻辑
```javascript
// index.html
document.querySelector('#mode-a-button').addEventListener('click', function() {
  window.location.href = './mode-a.html';
});
```

---

### 2. 模式A主界面 → 一键选品

#### 用户操作
- 点击"一键选品"快捷操作卡片

#### 系统响应
- 页面跳转到 selection-a.html
- 检查授权状态

#### 交互逻辑
```javascript
// mode-a.html
document.querySelector('#one-click-selection').addEventListener('click', function() {
  window.location.href = './selection-a.html';
});
```

---

### 3. 一键选品完整流程

#### 3.1 检查授权状态（首次使用）

**页面加载时**：
- 检查是否已授权店铺

**若未授权**：
1. 显示授权按钮
2. 点击授权按钮
3. 跳转到授权页面
4. 用户完成授权
5. 返回 selection-a.html
6. 显示店铺信息

**若已授权**：
- 显示店铺信息
- 显示匹配结果

#### 3.2 自动匹配商品

**系统行为**：
1. 根据店铺类目自动匹配商品
2. 调用后端API：`matchProducts(shopId)`
3. 返回匹配结果列表

**匹配结果展示**：
- 商品名称
- 价格
- 爆品分数
- 类型标注（长周期、短周期、趋势品）
- "已选"状态

#### 3.3 批量选择商品

**用户操作**：
- 点击"一键全选"按钮
- 或逐个点击商品卡片的选择按钮

**系统响应**：
- 所有商品或指定商品变为"已选"状态
- 显示已选商品数量
- 启用"一键上架"按钮

#### 3.4 一键上架

**用户操作**：
- 点击"一键上架"按钮

**系统响应**：
1. 调用后端API：`batchUpload(selectedProducts)`
2. 批量上架商品
3. 显示上架进度
4. 显示成功数量和失败数量
5. 显示AI助手建议

**AI助手建议**：
```
"已成功上架38个商品，预计明日流量提升20%，
建议明天继续铺货30-40个商品。"
```

#### 3.5 返回主界面

**用户操作**：
- 点击"返回"按钮

**系统响应**：
- 返回 mode-a.html
- 更新今日数据概览

### 5. 一键货源完整流程

#### 5.1 显示已选商品

**页面加载时**：
- 显示已选商品列表
- 显示建议售价

#### 5.2 匹配货源

**用户操作**：
- 点击"匹配货源"按钮

**系统响应**：
1. 调用后端API：`matchSupply(selectedProducts)`
2. 自动对接1688货源库
3. 找货、比价、过滤劣质供应商
4. 返回货源列表

**货源展示**：
- 平台（1688）
- 价格
- 评分
- 时效
- 利润计算

#### 5.3 供应商筛选

**用户操作**：
- 点击"筛选"按钮
- 选择筛选条件（评分、时效）
- 点击"应用筛选"

**系统响应**：
- 过滤货源列表
- 显示符合条件的货源

#### 5.4 选择供应商

**用户操作**：
- 点击每个商品的"选择供应商"按钮
- 选择最佳供应商

**系统响应**：
- 标记为已选供应商
- 显示已选数量

#### 5.5 一键下单

**用户操作**：
- 点击"一键下单"按钮

**系统响应**：
1. 调用后端API：`batchOrder(suppliers)`
2. 批量下单
3. 显示下单进度
4. 显示成功数量和失败数量

#### 5.6 返回主界面

**用户操作**：
- 点击"返回"按钮

**系统响应**：
- 返回 mode-a.html
- 更新今日数据概览

**系统响应**：

#### 9.4 一键执行维护

**用户操作**：
- 点击"一键执行维护"按钮

**系统响应**：
1. 调用后端API：`executeMaintenance(plan)`

**系统响应**：

**用户操作**：

**系统响应**：
- 返回 mode-a.html
