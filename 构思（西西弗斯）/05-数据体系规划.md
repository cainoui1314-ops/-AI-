# 数据体系规划

## 选品数据体系

### 1. 长周期选品

#### 数据来源
- 看去年同期的"词"（热搜）与"品"（热卖）

#### 数据用途
- 供应链备货
- 提前1-2季度趋势分析

#### 数据示例
- 分析去年7月凉鞋搜索词，如"洞洞鞋"、"绑带鞋"
- 分析去年7月凉鞋热卖品，如"XXX品牌凉鞋"

#### 数据结构
```json
{
  "category": "凉鞋",
  "time_range": "去年7月",
  "hot_keywords": ["洞洞鞋", "绑带鞋", "凉感"],
  "hot_products": [
    {
      "name": "XXX品牌凉鞋",
      "sales": 10000,
      "gmv": 500000
    }
  ]
}
```

#### 应用场景
- 供应链提前备货
- 提前设计选品策略
- 避免错过季节性机会

---

### 2. 短周期-爆品

#### 数据来源
- 看当下高GMV/销量榜单

#### 数据用途
- 快速跟卖
- 短期内获得销量

#### 数据示例
- 今日GMV榜单Top 100
- 今日销量榜单Top 100
- 最近7天GMV榜单Top 100

#### 数据结构
```json
{
  "time_range": "今日",
  "top_gmv": [
    {
      "name": "夏季冰丝袖套",
      "gmv": 100000,
      "sales": 5000
    }
  ],
  "top_sales": [
    {
      "name": "便携式车载小风扇",
      "sales": 10000,
      "gmv": 50000
    }
  ]
}
```

#### 应用场景
- 快速跟卖当下爆品
- 短期内获得销量
- 适合铺货型商家

---

### 3. 短周期-趋势品

#### 数据来源
- 看高增速的腰部商品

#### 数据用途
- 捕捉下一波机会
- 提前布局趋势品

#### 数据示例
- 最近7天增速Top 100
- 最近30天增速Top 100
- 增速趋势图

#### 数据结构
```json
{
  "time_range": "最近7天",
  "trend_products": [
    {
      "name": "出游分装瓶套装",
      "growth_rate": 150,
      "sales_trend": [100, 150, 200, 250]
    }
  ]
}
```

#### 应用场景
- 捕捉下一波趋势
- 提前布局趋势品
- 适合精品型商家

---

### 4. 数据合规

#### 脱敏处理
- 商品名称脱敏
- 商家信息脱敏
- 用户数据脱敏

#### 指数化处理
- 销量指数化（0-100）
- GMV指数化（0-100）
- 增速指数化（0-100）

#### 区间化处理
- 价格区间（0-50, 50-100, 100-200, 200+）
- 销量区间（0-100, 100-500, 500-1000, 1000+）
- GMV区间（0-1000, 1000-10000, 10000-100000, 100000+）

#### 确保可用性
- 所有数据都可以用于决策
- 不提供精确数据，但提供足够的信息
- 遵守数据隐私法规

## 交互形态数据

### 对话式Agent数据流

#### 用户意图识别
- 识别用户想要做什么
- 例如："我要找凉鞋的爆品" → 意图：选品

#### 上下文管理
- 记录对话历史
- 记录用户偏好
- 记录用户操作

#### 能力调用
- 根据用户意图调用后端能力
- 例如：选品能力 → 匹配爆品
- 例如：分析能力 → 分析竞品

#### 结果生成
- 生成聚焦的报告
- 生成操作建议
- 生成可视化图表

#### 数据结构示例
```json
{
  "conversation_id": "conv-001",
  "user_intent": "find_trending_products",
  "context": {
    "category": "凉鞋",
    "time_range": "最近7天"
  },
  "backend_call": {
    "api": "match_products",
    "params": {
      "category": "凉鞋",
      "type": "short-cycle-trend"
    }
  },
  "result": {
    "products": [
      {
        "name": "夏季凉感透气凉鞋",
        "price": 79,
        "score": 85,
        "trend": "up"
      }
    ]
  }
}
```

## 爆品追踪数据

### 流量数据

#### 数据维度
- 时间：每日、每小时
- 流量来源：投流、自然
- 流量载体：短视频、直播、商品卡
- 流量入口：平台入口

#### 数据结构
```json
{
  "product_id": "prod-001",
  "traffic_data": {
    "daily": [
      {
        "date": "2024-05-01",
        "total_traffic": 10000,
        "paid_traffic": 6000,
        "natural_traffic": 4000,
        "video_traffic": 5000,
        "live_traffic": 3000,
        "card_traffic": 2000
      }
    ]
  }
}
```

### 销量数据

#### 数据维度
- 时间：每日、每小时
- 销量：每日销量
- GMV：每日GMV

#### 数据结构
```json
{
  "product_id": "prod-001",
  "sales_data": {
    "daily": [
      {
        "date": "2024-05-01",
        "sales": 500,
        "gmv": 25000
      }
    ]
  }
}
```

### 关键动作数据

#### 数据维度
- 时间：动作发生时间
- 动作类型：调价、换图、达人合作
- 动作内容：调价到XX元、换图到XX图片、合作达人XX
- 动作影响：流量变化、销量变化

#### 数据结构
```json
{
  "product_id": "prod-001",
  "key_actions": [
    {
      "time": "2024-05-10 10:00:00",
      "action_type": "price_change",
      "action_content": {
        "old_price": 99,
        "new_price": 79
      },
      "impact": {
        "traffic_change": "+50%",
        "sales_change": "+30%"
      }
    },
    {
      "time": "2024-05-12 14:00:00",
      "action_type": "image_change",
      "action_content": {
        "old_image": "image-001",
        "new_image": "image-002"
      },
      "impact": {
        "traffic_change": "+20%",
        "sales_change": "+15%"
      }
    }
  ]
}
```

### 归因分析数据

#### 归因逻辑
- 分析关键动作对数据的影响
- 识别哪个动作导致了流量/销量变化
- 计算影响程度

#### 数据结构
```json
{
  "product_id": "prod-001",
  "attribution": {
    "primary_cause": "price_change",
    "primary_impact": {
      "traffic_change": "+50%",
      "sales_change": "+30%"
    },
    "secondary_cause": "image_change",
    "secondary_impact": {
      "traffic_change": "+20%",
      "sales_change": "+15%"
    },
    "conclusion": "价格调整是流量和销量增长的主要原因"
  }
}
```

## 竞品分析数据

### 标题分析数据

#### 分析维度
- 词汇结构：标题由哪些词汇组成
- 关键词布局：关键词的位置和顺序
- 标题长度：标题的字数
- 标题优化：标题优化建议

#### 数据结构
```json
{
  "competitor_product_id": "comp-001",
  "title_analysis": {
    "title": "夏季凉感透气凉鞋男女同款防紫外线",
    "word_structure": ["夏季", "凉感", "透气", "凉鞋", "男女同款", "防紫外线"],
    "keyword_layout": [
      {
        "keyword": "夏季",
        "position": 0
      },
      {
        "keyword": "凉感",
        "position": 1
      }
    ],
    "title_length": 18,
    "strength": "关键词布局合理，覆盖了主要搜索词"
  }
}
```

### 主图分析数据

#### 分析维度
- 构图：主图的构图方式
- 元素：主图中包含的元素
- 文案：主图中的文案内容
- 风格：主图的整体风格

#### 数据结构
```json
{
  "competitor_product_id": "comp-001",
  "main_image_analysis": {
    "image_url": "image-001",
    "composition": "居中构图",
    "elements": ["模特", "场景", "道具", "文案"],
    "copywriting": "清凉一夏",
    "style": "清新自然",
    "strength": "构图简洁，元素丰富，文案有力"
  }
}
```

### 价格分析数据

#### 分析维度
- 价格定位：价格在同类商品中的位置
- SKU策略：SKU数量和价格区间
- 定价策略：定价的合理性

#### 数据结构
```json
{
  "competitor_product_id": "comp-001",
  "price_analysis": {
    "price": 79,
    "price_positioning": "中等价位",
    "sku_strategy": {

        "min": 69,
        "max": 89
      }
    },
    "pricing_strategy": "定价合理，覆盖主流消费群体"
  }
}
```

- GMV榜单：每日更新

- 月度报告：每月更新
